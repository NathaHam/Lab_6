# SplitSmart — Requirement-by-Requirement Cross-Review Matrix

**Ratings:** Complete = coherent design coverage with no material known gap for the stated scope; Partial = meaningful design exists but a decision, edge case, or full-product detail remains; Missing = no design coverage found; Contradictory = design conflicts with a source requirement. Ratings assess proposal documents, not implementation.

**Sources:** `UserRequirement.md`, `.specify/memory/constitution.md`, `spec.md`; Proposal A `design/speckit/`; Proposal B `design/claude/`.
